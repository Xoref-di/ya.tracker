# Плагин для Яндекс Трекера: Оформление связанной задачи

Плагин-расширение для Яндекс Трекера, который автоматизирует и упрощает создание задач на основе заполненных форм (например, на замену оборудования, вызов подрядчика или сетевого оборудования). 

## Возможности
- Быстрое создание задач через кастомные формы.
- Готовые шаблоны для разных типов заявок (замена ПК, принтера, сетевого оборудования, вызов мастера, поставки задач в другие проекты и т.д.).
- Автоматическое заполнение полей задачи на основе ответов из Яндекс Форм.
- Интеграция с очередями Яндекс Трекера.
