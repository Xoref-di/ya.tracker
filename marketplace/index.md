# Создание связанной задачи

Создание связанной задачи в Tracker с выбором проекта и автоматическим заполнением полей.

## Возможности

- создание связанной задачи из текущей задачи;
- выбор проекта;
- автоматическое заполнение полей;
- перенос автора и наблюдателей родительской задачи для ITEQIPHO;
- для других проектов перенос исполнителя в авторы задачи и описание задач;

## Для кого

Плагин предназначен для пользователей Tracker, которым нужно быстро создавать связанные задачи из существующих задач.

## Как использовать

1. Откройте задачу в Tracker.
2. Откройте сверху справа Плагины.
3. Выберите «Создание связанной задачи».
4. Выберите проект и заполните необходимые поля.
5. Создайте задачу.
6. Заполните обязательные поля, если отобразятся.
